Здесь появятся протоколы встреч

Когда начнётся встреча в Zoom, запись включится сама. После звонка Meeting Agent расшифрует разговор и составит протокол: кратко, решения, задачи и открытые вопросы.

Можно и вручную: кнопка «Записать» слева или перетащите сюда аудиофайл, например запись с диктофона.

Свой шаблон протокола

По каждому пункту модель запишет, что о нём прозвучало на встрече. Плюс разделы «Кратко», «Задачи», «Открытые вопросы».

Первой строкой ответа модель должна писать «TITLE: название» — из неё берётся заголовок заметки (если строки нет, приложение добавит это указание само).
