# Правила участия

Спасибо, что хотите помочь Meeting Agent! Ниже — как устроен проект и как предложить изменения.

## Сообщить об ошибке или предложить идею

Создайте задачу (Issue) и укажите:
- систему и версию: macOS (чип) или Windows (процессор, видеокарта), версию приложения;
- что делали, что ожидали и что произошло;
- журналы: macOS — `~/Library/Application Support/Meeting Agent/logs/backend.log`, Windows — `%LOCALAPPDATA%\Meeting Agent\logs` (`app.log`, `backend.log`, `llama-server.log`).

**Перед отправкой уберите из журналов фрагменты расшифровок, имена коллег и ключи.** Не прикладывайте записи встреч.

Об уязвимостях — не в открытых задачах, а по [политике безопасности](SECURITY.md).

## Как устроен проект

| Папка / файл | Что там |
|---|---|
| `meeting_agent/` | Python: распознавание, разделение собеседников, протоколы, локальный сервер интерфейса |
| `ui/` | интерфейс (HTML/JS/CSS), общий для Mac и Windows |
| `app/` | оболочка macOS на Swift: строка меню, окно, запись звука |
| `meeting_agent/winapp.py`, `winrec.py`, `windows/` | оболочка и запись для Windows |
| `meeting_agent/osutil.py` | все различия macOS и Windows в одном месте |
| `templates/` | шаблоны протоколов — обычные инструкции для модели |
| `build_app.sh`, `build_windows.sh` | сборка приложения для Mac и архива для Windows (оба — на Mac) |

## Разработка

Нужен Mac на Apple Silicon.

```bash
./setup.sh                                 # окружение .venv, рекордер, модели
./agent web                                # интерфейс в браузере
./agent process ~/Downloads/a.m4a          # обработать аудиофайл
./build_app.sh --install                   # собрать и установить приложение
./build_windows.sh                         # собрать build/Meeting-Agent-Windows.zip (нужны uv и zig)
```

Код для Windows собирается на Mac, но проверять его нужно на настоящей Windows: запись звука (WASAPI), окна Zoom и CUDA на Mac не проверить.

## Правила для изменений

- **Конфиденциальность прежде всего.** Звук и расшифровка не должны уходить в сеть без явного выбора пользователя. Новые облачные функции — только по выбору и с предупреждением в интерфейсе.
- **Никаких секретов и данных в репозитории:** ключей, токенов, записей, расшифровок, слепков голоса, личных имён. Проверьте `git diff` перед коммитом.
- **Обе платформы.** Различия macOS и Windows — через `osutil.py` (`IS_WIN`, `PC` и т. д.), а не разбросанными проверками. Тексты интерфейса — без «на этом Mac» там, где речь и о Windows.
- **Язык.** Интерфейс, сообщения пользователю и комментарии в коде — на русском, простыми словами.
- **Тяжёлое — по желанию.** Большие загрузки (модели, библиотеки CUDA) — по кнопке, с продолжением после обрыва, а не в общем архиве.
- **Проверка.** Опишите в запросе на слияние, на чём проверяли (Mac / Windows, какие модели, какая встреча) и что не удалось проверить.

## Запрос на слияние (Pull Request)

1. Сделайте форк и ветку от `main`.
2. Небольшие, законченные изменения с понятным описанием на русском.
3. Если меняется поведение — обновите `README.md`.
4. Участвуя, вы соглашаетесь с [кодексом поведения](CODE_OF_CONDUCT.md) и с тем, что ваш вклад распространяется по [лицензии MIT](LICENSE).
