# Что нового в Meeting Agent

Формат: версия (дата) → «Новое», «Исправлено», «Windows», «Для разработчиков». Версия кода — `app` в `version.json`;
окно «Обновления» показывает раздел нужной версии. Новые изменения — в самый верх, в раздел «Готовится».

## Готовится

## 1.3.1 (20.11.2026)

### Новое
- **Обновления с двух площадок** — GitVerse и GitLab опрашиваются одновременно, код скачивается с той, что доступна (если одна не отвечает — с другой).

### Исправлено
- Расшифровка: время у реплики больше не наезжает на имя; у каждой реплики — кнопка «▶ 00:01:23», запись играет с этого места.

### Windows
- Маленький установщик стал ещё меньше (~11 МБ): установщик пакетов uv скачивается с PyPI при первом запуске (с проверкой контрольной суммы).
- Сборки для скачивания — также на [GitLab](https://gitlab.com/sir1knight/Meeting_agent/-/releases).

## 1.3.0 (20.11.2026)

### Новое
- **Окно «Обновления»** — всё в одном месте: код и интерфейс, пакеты Python (Windows), модели, ускорение NVIDIA, оболочка; кнопка «Обновить всё».
- **Обновления по компонентам с GitVerse** без переустановки: код и интерфейс скачиваются и применяются при перезапуске — когда удобно («Перезапустить сейчас» / «Отменить»), откат к версии из приложения.
- Тихая проверка обновлений при запуске (не чаще раза в сутки); плашка «Доступны обновления» в боковой панели — только когда есть что обновить.
- **Плеер в расшифровке**: нажмите на время у реплики — запись играет с этого места, текущая реплика подсвечивается.
- **Вкладка «Спросить»** у каждой встречи: вопросы обычными словами и готовые задания — письмо-итог участникам, задачи таблицей, что не решено, рекомендации, кратко за 30 секунд.
- **«Скачать…»**: протокол (по желанию с расшифровкой) в Word (.docx), PDF или Markdown.
- **Свои шаблоны протоколов**: из списка пунктов или чек-листа, своей инструкцией или на основе встроенного.
- **Автозапись Microsoft Teams, Яндекс Телемоста и звонков в браузере** (Google Meet и др.) — по тому, какая программа пишет микрофон; галочки по платформам.
- **Участники и название встречи из календаря** (Mac — «Календарь», Windows — Outlook).
- **Проверка ключей API** (Gemini, ChatGPT, Claude): быстрая — ключ и модель, полная для Gemini — пробная генерация с расшифровкой ошибок (регион, лимиты).
- Модели Gemini 3.x бесплатного уровня, по умолчанию `gemini-3.8-flash`; модели старше 3.1 скрыты.

### Исправлено
- Обрыв связи с облачным сервисом (например, при переподключении VPN) — запрос повторяется до трёх раз, а не падает сразу.
- Проверка ключа Gemini больше не ждёт минуту ответа модели и не пишет «нет связи» при рабочем ключе.
- Если на GitVerse нет сведений об обновлениях — понятное сообщение вместо «ошибки 400».
- Кнопка в боковой панели больше не вылезает за край.

### Windows
- **Маленький установщик** (~25 МБ) — пакеты Python (~350 МБ) докачиваются при первом запуске с PyPI; полный архив (~350 МБ) остаётся.
- PDF — через Edge без окна.

## 1.2.0 (19.11.2026)

### Новое
- **Версия для Windows 10/11** из того же кода: значок в трее, окно на Edge WebView2, запись микрофона и звука компьютера (WASAPI), автозапись Zoom, автозапуск, ярлык в «Пуске».
- **Подбор под компьютер при первом запуске** (Windows): процессор, память, видеокарта → рекомендованные распознавание, модель протоколов и ускорение.
- **Ускорение NVIDIA** (Windows, по кнопке): llama.cpp с CUDA 12.4 — Qwen на видеокарте; cuBLAS и cuDNN — Whisper на видеокарте.
- Проект опубликован: [GitVerse](https://gitverse.ru/sir1knight/Meeting_agent), лицензия Apache 2.0, политика безопасности, кодекс поведения, правила участия.

### Исправлено
- Windows: окно не открывалось с ошибкой «Failed to resolve Python.Runtime.Loader.Initialize» — приложение само снимает блокировку «из интернета» с библиотек; если окно всё равно не откроется — интерфейс в браузере.
- Windows, по итогам код-ревью: пропуски тишины по монотонным часам (подводка часов не сдвигает дорожку); типы HANDLE/HWND в вызовах Windows API; ложная остановка сервера при отказе в доступе к процессу; понятная ошибка без устройства вывода звука; «Показать в Проводнике»; занятые DLL при переустановке ускорения NVIDIA; апострофы в пути ярлыка; «на этом Mac» в тексте на Windows.
- Тексты: «на компьютере, где установлено приложение» вместо «на этом Mac».

## 1.1.0 (18.11.2026)

### Новое
- **Протоколы через Gemini API и ChatGPT (OpenAI API)** по ключу; выбор модели Gemini, в том числе бесплатной Flash; понятное сообщение об исчерпанном лимите.
- **Первый запуск**: выбор из трёх моделей распознавания (Whisper turbo, Whisper large-v3, GigaAM); поля для ключей API под выбранным вариантом; инструкция, как подключить Claude по подписке (Claude Code); шаг с токеном Hugging Face и проверкой доступа к моделям pyannote.
- Готовый архив приложения, чтобы поделиться с коллегами.

### Исправлено
- После ручной остановки запись сама начиналась снова, пока окно Zoom было открыто, — теперь эта встреча больше не записывается.
- Проверка токена Hugging Face всегда отвечала «не принял токен».

## 1.0.0 (до 18.11.2026)

Первая версия для Mac (Apple Silicon): сама замечает встречу в Zoom и записывает её; распознавание (Whisper, GigaAM) и в ходе встречи;
разделение собеседников (pyannote) и слепки голоса; протоколы по шаблонам — локально (Qwen 2.5 7B) или через Claude
(по подписке или API); умный поиск по встречам; список участников; угадывание имён по разговору; импорт аудиофайлов.
