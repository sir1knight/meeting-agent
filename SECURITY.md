# Политика безопасности

Meeting Agent работает с записями рабочих встреч, расшифровками, слепками голоса и ключами API, поэтому к безопасности мы относимся серьёзно.

## Поддерживаемые версии

Исправления выходят только для последней версии из раздела «Релизы» и ветки `main`.

## Как сообщить об уязвимости

**Не публикуйте подробности уязвимости в открытых задачах (Issues).**

1. Напишите автору репозитория `sir1knight` личным сообщением на GitVerse или создайте задачу с заголовком «Уязвимость: прошу контакт для связи» — без технических деталей.
2. Опишите: что можно сделать, на какой системе (macOS / Windows, версия приложения), шаги воспроизведения и что, по-вашему, может пострадать (записи, ключи, компьютер пользователя).
3. Мы подтвердим получение в течение 7 дней, оценим проблему и сообщим, когда выйдет исправление. После выхода исправления можно опубликовать подробности; по желанию укажем вас в описании релиза.

## Что считается уязвимостью

- доступ к записям, расшифровкам, заметкам или слепкам голоса со стороны другого пользователя, сайта или программы;
- утечка ключей API, токена Hugging Face или токена локального сервера;
- выполнение чужого кода через приложение, его локальный сервер, загружаемые модели или библиотеки;
- отправка данных в сеть без ведома пользователя (например, при выбранной локальной модели).

Не считаются уязвимостью: то, что для облачных вариантов протоколов текст расшифровки уходит в выбранный сервис (это описано в интерфейсе), и предупреждения Windows SmartScreen / macOS Gatekeeper о неподписанной сборке.

## Как устроена защита

- **Данные остаются на компьютере.** Звук распознаётся локально; в сеть может уйти только текст расшифровки и только при выборе облачного варианта (Claude, Gemini, ChatGPT).
- **Локальный сервер интерфейса** слушает только `127.0.0.1` на случайном порту, проверяет заголовок `Host` (защита от подмены DNS) и требует случайный токен в каждом запросе к API.
- **Секреты** (ключи API, токен Hugging Face) хранятся в отдельных файлах в папке данных приложения: на macOS — с правами `600` (только владелец), на Windows — в `%LOCALAPPDATA%` профиля пользователя. В репозиторий и сборки они не попадают.
- **Загрузки** идут только с официальных источников: Hugging Face (модели), GitHub-релизы ggml-org/llama.cpp и PyPI (библиотеки CUDA для Windows), по HTTPS.
- **Слепки голоса** — биометрические персональные данные; хранятся только локально в `~/MeetingAgent/voices`.

## Ответственность пользователя

Предупреждайте участников встреч о записи и запоминании голосов и сверяйтесь с правилами вашей организации о передаче расшифровок во внешние сервисы.
