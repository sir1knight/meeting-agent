# Meeting Agent — локальный аналог Plaud для встреч в Zoom

Сам замечает начало встречи в Zoom и записывает её. Когда встреча заканчивается, расшифровывает разговор, разделяет собеседников и пишет протокол: кратко, решения, задачи (кто, что, срок) и открытые вопросы.

Работает на **Mac (Apple Silicon)** и **Windows 10/11**. Готовые сборки — в разделе «Релизы» репозитория на [GitVerse](https://gitverse.ru/sir1knight/Meeting_agent).

**Звук и расшифровка всегда распознаются на вашем компьютере.** В сеть может уйти только текст расшифровки — и только если для протоколов выбран облачный вариант.

## Кто пишет протокол

| Вариант | Что нужно | Что уходит в сеть | Цена |
|---|---|---|---|
| **Локально (Qwen 2.5 7B)** | скачать модель ~4,3 ГБ (Mac) / ~4,7 ГБ (Windows) | ничего | бесплатно |
| **Claude по подписке** | установленный Claude Code и подписка Claude | текст расшифровки → Anthropic | входит в подписку, тратит её лимиты |
| **Claude API** | API-ключ Anthropic (`sk-ant-…`) | текст расшифровки → Anthropic | ~0,2–0,4 $ за часовую встречу |
| **Gemini API** | API-ключ Google (`AIza…`) | текст расшифровки → Google | бесплатно на Gemini Flash (с лимитами), платные модели — по тарифу |
| **ChatGPT (OpenAI API)** | API-ключ OpenAI (`sk-…`) | текст расшифровки → OpenAI | по тарифу OpenAI, обычно центы за встречу |

Перед облачными вариантами уточните, разрешено ли отправлять расшифровки рабочих встреч во внешний сервис.

### API-ключи

Ключ вводится прямо в окне приложения: при первом запуске под выбранным вариантом или потом в «Настройках». Ключи хранятся только на этом компьютере в отдельных файлах с доступом лишь для вашей учётной записи (`.anthropic_key`, `.gemini_key`, `.openai_key` в папке данных приложения) и никуда, кроме своего сервиса, не отправляются.

- **Claude API** — ключ создаётся на [console.anthropic.com](https://console.anthropic.com/) → API Keys. Модель по умолчанию: `claude-opus-5-5`.
- **Gemini API** — ключ создаётся на [aistudio.google.com](https://aistudio.google.com/apikey). Модель выбирается в настройках из списка доступных вашему ключу; по умолчанию `gemini-3.8-flash`. Бесплатно (без оплаты, только с ключом) доступны `gemini-3.8-flash`, `gemini-3.6-flash`, `gemini-3.5-flash-lite` и `gemini-3.1-flash-lite`; модели старше 3.1 приложение не показывает. Кнопка «Проверить ключ» делает пробный запрос и сообщает, работает ли ключ и выбранная модель (то же для Claude API и ChatGPT).
- **ChatGPT** — ключ создаётся на [platform.openai.com](https://platform.openai.com/api-keys) (нужен баланс на счёте API, подписка ChatGPT Plus сюда не относится). Модель по умолчанию: `gpt-5`.
- **Claude по подписке** — ключ не нужен. Установите Claude Code и один раз войдите:
  - Mac: `curl -fsSL https://claude.ai/install.sh | bash`, затем `claude`;
  - Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`, затем `claude`.

Облачные модели получают расшифровку целиком, поэтому пишут протокол быстрее и обычно точнее локального Qwen, который читает длинные встречи по частям.

## Модели распознавания речи

Выбираются при первом запуске и меняются в «Настройках → Распознавание речи». Все работают офлайн.

| Модель | Размер | Особенности |
|---|---|---|
| **Whisper large-v3-turbo** (OpenAI) | ~1,6 ГБ | быстрая, многоязычная; чаще ошибается на именах и в шуме |
| **Whisper large-v3** (OpenAI) | ~3,1 ГБ | точнее turbo, обработка примерно вдвое дольше |
| **GigaAM-v3** (Сбер) | ~0,45 ГБ | обучена на русской речи, включая созвоны; самая быстрая на обычном процессоре |

Откуда берутся:
- Mac — Whisper в формате MLX (`mlx-community/whisper-large-v3-turbo`, `mlx-community/whisper-large-v3-mlx`), работает на видеоядрах Apple;
- Windows — Whisper в формате CTranslate2 через faster-whisper (`deepdml/faster-whisper-large-v3-turbo-ct2`, `Systran/faster-whisper-large-v3`), на видеокарте NVIDIA после загрузки «Ускорения NVIDIA» (см. ниже), иначе на процессоре;
- GigaAM — `ai-sage/GigaAM-v3` на обеих системах.

Распознавание по ходу встречи работает с GigaAM и Whisper turbo (на Windows — только с GigaAM).

Остальные модели:
- **Протоколы локально** — Qwen 2.5 7B Instruct: на Mac `mlx-community/Qwen2.5-7B-Instruct-4bit` (MLX), на Windows `bartowski/Qwen2.5-7B-Instruct-GGUF` (Q4_K_M, llama.cpp).
- **Разделение собеседников** — pyannote `speaker-diarization-3.1` (+ `segmentation-3.0` и `wespeaker-voxceleb-resnet34-LM`), ~30 МБ.

## Windows: подбор под компьютер и ускорение NVIDIA (CUDA)

Сборка для Windows одна на все компьютеры. **При первом запуске** приложение определяет процессор, память и видеокарту, показывает карточку «Ваш компьютер» и сразу выбирает подходящие варианты (их можно поменять):

| Компьютер | Распознавание | Протоколы | Ускорение NVIDIA |
|---|---|---|---|
| NVIDIA от 8 ГБ видеопамяти (RTX 3070/4070/4080 и т. п.) | GigaAM | Qwen на видеокарте | рекомендуется |
| NVIDIA с малой видеопамятью (MX150, GTX 1050) | GigaAM | Gemini Flash | по желанию (ускорит только Whisper) |
| Без NVIDIA (Intel, AMD) | GigaAM | Gemini Flash | — |

**Ускорение NVIDIA** — необязательная загрузка (~1,45 ГБ) на шаге первого запуска или в «Настройках». В архив приложения входят только сборки для процессора, библиотеки CUDA скачиваются по кнопке:
- **llama.cpp с CUDA 12.4** — официальная сборка [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) (`b12549`). Qwen работает в отдельном процессе `llama-server` целиком на видеокарте; после протокола процесс закрывается и освобождает видеопамять. Нужно от 7 ГБ видеопамяти.
- **CUDA 12 (cudart, cuBLAS)** из той же сборки и **cuDNN 9** (пакет NVIDIA `nvidia-cudnn-cu12` с PyPI) — с ними Whisper (faster-whisper / CTranslate2) считает на видеокарте в float16 (на старых картах — в формате, который выберет CTranslate2).

Подробности:
- Нужен драйвер NVIDIA с поддержкой CUDA 12.4 (версия 551 и новее). Видеокарта определяется через `nvidia-smi`.
- Файлы лежат в `%LOCALAPPDATA%\Meeting Agent\gpu`, загрузка докачивается после обрыва. Кнопка «Удалить» в настройках возвращает всё на процессор.
- Если на видеокарте что-то не заработало, приложение само переходит на процессор. Журнал Qwen — `logs\llama-server.log`.
- GigaAM и разделение собеседников (PyTorch) остаются на процессоре: сборка PyTorch с CUDA весит ещё ~2,5 ГБ, а на современном процессоре они и так быстрые.
- Встроенная графика Intel и видеокарты AMD не используются.

## Hugging Face

Все модели скачиваются с [huggingface.co](https://huggingface.co) один раз, потом приложение работает без интернета. Загрузка докачивается после обрыва.

- **Whisper, GigaAM и Qwen** — открытые, токен не нужен.
- **pyannote (разделение собеседников)** — закрытые модели, нужен бесплатный токен:
  1. Зарегистрируйтесь на huggingface.co и создайте токен типа **Read** (Settings → Access Tokens).
  2. Нажмите «Agree and access repository» на страницах [speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1) и [segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0).
  3. В приложении (первый запуск, шаг «Разделение собеседников», или «Настройки») вставьте токен, нажмите «Проверить» — приложение покажет, принят ли токен и открыт ли доступ к каждой модели, — затем «Скачать модель».

Токен хранится только на этом компьютере (файл `.hf_token`) и нужен лишь для скачивания. Без разделения собеседников всё работает, просто вся речь собеседников подписывается одним «Собеседник»; ваша речь всегда подписана «Я».

## Приложение

```bash
./build_app.sh            # собрать build/Meeting Agent.app (~1,6 ГБ)
./build_app.sh --install  # собрать и сразу положить в /Applications
```

Готовое `Meeting Agent.app` перетащите в «Программы» и запустите. В строке меню появится значок волны, откроется окно.

- **Первый запуск.** Выберите, кто пишет протоколы, и скачайте модели. Загрузка докачивается после обрыва. Модели и настройки хранятся в `~/Library/Application Support/Meeting Agent`.
- **Разрешения.** При первой записи macOS спросит доступ к **микрофону** и к **записи экрана и системного звука**. Без второго не слышно собеседников и не определяется начало встречи. Чтобы разрешения не сбрасывались после пересборки, создайте один раз сертификат подписи `Meeting Agent Local` (Keychain Access → Certificate Assistant → Create a Certificate…, Self-Signed Root, Code Signing, затем Trust → Code Signing: Always Trust) — `build_app.sh` подпишет им приложение.
- **Окно.**
  - Список встреч, протокол и расшифровка.
  - «Пересоздать…»: другой шаблон или модель без повторной расшифровки.
  - «Импорт записи» или перетаскивание аудиофайла.
  - Настройки: модель распознавания, кто пишет протоколы, API-ключи, токен Hugging Face, глоссарий, автозапись.
- **Строка меню.** «Записать сейчас» записывает весь звук системы и микрофон: подходит для Teams, Телемоста или браузера. Там же переключатели «Записывать встречи Zoom автоматически» и «Запускать при входе в систему».
- Заметки сохраняются в `~/MeetingAgent/notes` как обычные Markdown-файлы, записи — в `~/MeetingAgent/recordings`.
- Лог: `~/Library/Application Support/Meeting Agent/logs/backend.log`.

### Разделение собеседников

Для подписей «Собеседник 1», «Собеседник 2» нужна модель pyannote и токен Hugging Face — см. раздел [Hugging Face](#hugging-face). Ваша речь всегда подписана «Я»: микрофон пишется отдельной дорожкой.

### Список участников

Если указать, кто будет на встрече, расшифровка и подписи получаются точнее.
- **До встречи:** строка «＋ Участники следующей встречи» в боковой панели. Список достанется ближайшей записи или импортированному файлу.
- **Во время записи:** кнопка «Участники» в красной плашке.
- **После:** «＋ Указать участников» под заголовком встречи, затем «Пересоздать…» с галочкой «Заново расшифровать аудио».

Что даёт список:
- имена попадают в подсказку Whisper;
- слепки голоса людей из списка узнаются при пороге ниже на `participant_bonus` (0,1);
- угадывание по разговору выбирает имена из списка (Дарья → Даша);
- протокол пишет имена так, как они указаны;
- разделение собеседников ждёт не меньше «список − 1» голосов.

Имена из «Голосов» подсказываются в диалоге и тоже всегда уходят в подсказку Whisper.

### Умный поиск

Задайте вопрос в поле поиска обычными словами и нажмите Enter: «когда обсуждали передачу PPAN?», «что решили вчера?», «какие задачи на мне за неделю?». Даты («вчера», «на прошлой неделе», «26 октября») сужают круг встреч.
- **Как отвечает.** Приложение находит подходящие фрагменты протоколов и расшифровок, и модель отвечает по ним со ссылками [n]. Ссылка открывает встречу на нужном месте. Уточняющие вопросы задаются в том же разговоре.
- **Кто отвечает** (Настройки → «Умный поиск»):
  - Claude по подписке, Claude API или Gemini API — найденные фрагменты уходят в облако. Ключ Gemini вводится там же.
  - Qwen на этом компьютере — ничего не уходит в сеть.

### Если протокол не составился

Например, пропал интернет. Тогда встреча всё равно сохраняется с полной расшифровкой, а над протоколом появляется кнопка «Составить протокол». Она составляет только протокол, без повторного распознавания.

### Распознавание во время встречи

Пока идёт запись, приложение каждые ~20 секунд распознаёт новые куски. После встречи остаётся разделить собеседников и составить протокол. На встрече в 10 минут это около минуты вместо трёх, на часовой — несколько минут вместо четверти часа.
- **Модели:** работает только с лёгкими — GigaAM и Whisper turbo. С Whisper large-v3 всё распознаётся после встречи.
- **Приоритет пониженный**, чтобы не мешать Zoom.
- **От батареи не работает:** то, что не успело распознаться по ходу, досчитается после встречи.
- Выключается в Настройках → «Распознавание речи».

### Если собеседники перепутаны

- **Как распознаётся.** Дорожка собеседников сначала размечается по голосам, а потом каждая реплика распознаётся отдельно. Поэтому слова двух людей не попадают в один кусок.
- **Если разметка всё же склеила двоих.** Откройте вкладку «Расшифровка» и нажмите на имя у реплики → «Кто это сказал?». Выберите другого собеседника или «Новый собеседник». Расшифровка в заметке обновится сразу.
- **Пересоздание протокола.** Над протоколом появится плашка «Пересоздать протокол». При пересоздании для изменённых собеседников заново считаются слепки голоса и образцы, без повторного распознавания.

### Слепки голоса

Meeting Agent запоминает собеседников по голосу и на следующих встречах сам подписывает их по имени. Работает только при включённом разделении собеседников и полностью офлайн.

- **Как добавить человека.** Откройте встречу и нажмите на «Собеседник N» над протоколом. Введите имя и оставьте галочку «Запомнить голос». Если слепок с таким именем уже есть, голос добавится к нему, иначе будет создан новый. Имя заменится во всей заметке.
- **Как узнаётся.** На новой встрече голос каждого собеседника сравнивается со всеми слепками. Совпадение выше порога — подставляется имя. В серой зоне — имя со знаком «?»: нажмите на него, чтобы подтвердить или исправить. Ниже — «Собеседник N». Два собеседника одной встречи не получают один слепок.
- **Исправление.** Если имя подставлено автоматически, а вы его исправили, эта встреча больше не учит неверный слепок.
- **Предполагаемые имена «Олег*».** Безымянным собеседникам модель протокола подбирает имя по разговору. Основание: к человеку обратились по имени, и он сразу ответил; он представился; ему передали слово. Догадка отмечается звёздочкой, а в подсказке к чипу видна цитата-основание. Имя должно действительно звучать в записи, одно имя достаётся только одному собеседнику. Нажмите на «Олег*», чтобы подтвердить имя (и запомнить голос) или исправить его. «Сбросить имя» отклоняет догадку насовсем. Выключается в Настройках или в `config.toml` → `[names] guess = false`. В облачных вариантах протокола для угадывания тоже используется Claude.
- **Порядок подписей:** подтверждённое имя → «Имя (?)» по голосу → «Имя*» по разговору → «Собеседник N».
- **Раздел «Голоса».**
  - ▶ — прослушать образец.
  - Имя, почта и Telegram. Контакты появляются ссылками в чипах участников и в таблице задач.
  - «Заменить образец» — выбрать фрагмент из любой встречи.
  - «Объединить с…» — если один человек записан под двумя именами.
  - «Удалить».
- **Хранение.** `~/MeetingAgent/voices/<id>/profile.json` (имя, контакты, до 20 эмбеддингов — по одному на встречу) и `sample.wav`. В папке встречи: `speakers.json` (эмбеддинги собеседников) и `voices/*.wav` (их образцы). Слепок можно создать позже, без повторной обработки.
- **Пороги** в `config.toml`, раздел `[voices]`:

  | Параметр | Значение | Смысл |
  |---|---|---|
  | `match_threshold` | 0,75 | выше — уверенно подставить имя |
  | `uncertain_threshold` | 0,55 | от этого значения до 0,75 — серая зона со знаком «?», ниже — «Собеседник N» |
  | `min_speech_seconds` | 15 | если человек говорил меньше, только «?» |

  Калибровка на реальной встрече: тот же человек при 20+ секундах речи — 0,84–0,92, разные люди — до 0,54. Короткие или смешанные фрагменты дают 0,2–0,7, поэтому они уходят в серую зону.
- Встречи, обработанные до появления этой функции, пересоздайте с галочкой «Заново расшифровать аудио». Тогда у них появятся эмбеддинги собеседников.

Слепки голоса — биометрические персональные данные. Они хранятся только на компьютере, где установлено приложение, и никуда не отправляются; предупреждайте коллег о записи и запоминании голосов.

### Claude по подписке

Нужен установленный Claude Code (`brew install --cask claude-code`). Один раз выполните в Терминале `claude` и войдите по подписке Claude. Приложение вызывает `claude -p` без доступа к файлам и инструментам и передаёт только текст расшифровки.

## Командная строка (для разработки)

```bash
./setup.sh                                   # окружение .venv, рекордер, модели
./agent process ~/Downloads/a.m4a            # обработать аудиофайл
./agent process <папка> --template client --llm claude-code   # пересоздать протокол
./agent process <папка> --retranscribe       # расшифровать заново
./agent record --app all                     # записать сейчас (Ctrl+C — стоп)
./agent watch                                # ждать встречи Zoom
./agent serve --port 8765                    # сервер окна (для отладки интерфейса)
```

Из Терминала разрешения macOS выдаются Терминалу, а в приложении — самому Meeting Agent.

## Шаблоны

Лежат в `templates/`: это обычные инструкции для модели. `meeting` — рабочая встреча (по умолчанию), `standup` — стендап, `client` — встреча с партнёром, `interview` — custdev-интервью.

Цифры для Windows — оценка, на реальных компьютерах ещё не замерены.

Qwen на M1 Pro читает ~250–400 токенов/с и пишет ~20–30 токенов/с (на RTX 4080 — тысячи и ~100 токенов/с); часовая встреча — около 20 тыс. токенов. Смена шаблона или модели — только протокол, без повторной расшифровки.

## Ограничения

- **Наушники.** Если звук собеседников идёт из динамиков, он попадает в микрофон. Агент убирает такие дубли, но в наушниках результат чище.
- Если два человека говорят одновременно, фрагмент достаётся одному из них.
- Имена подставляются по слепкам голоса и по разговору; незнакомые люди остаются «Собеседник N», пока вы их не подпишете.
- На Windows записывается весь звук компьютера (не только Zoom): уведомления и видео тоже попадут в запись.
- Участники не получают уведомления о записи. Предупреждайте их и сверяйтесь с правилами компании.
